Walmart Customer Purchase & Sales Performance Analysis

Project Overview

This project analyzes Walmart online customer purchase data using Microsoft Excel to understand customer purchasing patterns, product performance, and sales trends.

Dataset

The dataset contains 50,000 transaction records, including purchase amounts, dates, product names, categories, customer demographics, ratings, discounts, and repeat-customer information.

Tools Used

Microsoft Excel

Data Cleaning

Data Analysis

Pivot Tables and Charts

Excel Dashboard

Key Analysis

Analyzed total and average purchase amounts.

Compared sales across product categories.

Identified top-performing products.

Examined sales trends over time.

Compared purchases with and without discounts.

Analyzed customer purchasing patterns and repeat customers.

Key Findings

Electronics was the highest-performing product category.

Headphones was the top-performing product.

Sales with and without discounts were nearly equal.

Repeat customers contributed approximately half of the total purchase amount.

Customers aged 25–54 showed strong purchasing activity.
